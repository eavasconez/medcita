# S10.5-06 — Capturas ANTES / DESPUÉS

Cada imagen compara la aplicación en `develop` (f365860, ANTES) con la rama S10.5-06 (DESPUÉS), con los mismos datos de demostración y el mismo backend. Las de «móvil» son de 390 × 844 px; el resto, de 1280 × 800. Las de «a media página» y «al final» se toman con el contenido ya desplazado para ver **qué queda a la vista**. Para provocarlas creé en una base desechable un borrador con texto, un diagnóstico y una toma de signos de la visita, una nota cerrada con una adenda, y el borrador de otra médica; el diálogo de cierre del ANTES es el de S10.5-02 (sin el resumen).
